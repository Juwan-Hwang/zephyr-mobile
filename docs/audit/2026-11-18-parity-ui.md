- 仓库：`/workspace/repos/zephyr-mobile`，分支 `main`，提交 `6ffbaa2`（#203 合并后）。只读审计，未改动、未提交、未评论。
- 依据（按优先级）：`design/prototype/index.html`（原型，COORDINATION §3“视觉以原型为准”）> `contract/zephyr-engine.md` / `contract/i18n.md` / `contract/i18n/glossary-v1.json` > `tokens/mobile.json` > `design/notes/mobile-design-spec.md`（v0.1 草案，部分已被原型取代）。
- 路径缩写：

## 4. 合理的平台差异（b，保留）

1. **大小写**：iOS 的 en/tr 用标题式，Android 和桌面用句首大写（`contract/i18n.md` §2 已写明）。

5. **下拉刷新**：iOS 订阅页下拉更新全部；Android 用“更新全部”行。都可接受。

7. **按需连接**：iOS 用 NEOnDemandRules；Android 对等的是系统“始终开启的 VPN”，App 不能自行开启。保留差异，但 Android 不应显示一个不生效的开关，见 #1。
8. **快捷入口**：iOS 有小组件、锁屏、灵动岛、控制中心、快捷指令；Android 有快速设置磁贴、Glance、常驻通知（断开 / 切全局）。符合规范 §5 和原型第 17 章。
