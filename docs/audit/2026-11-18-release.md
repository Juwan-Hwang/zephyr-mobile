# Zephyr Mobile v1.0 发版前审计（只读）

- 仓库：`/workspace/repos/zephyr-mobile`，main @ `6ffbaa2`（Merge #203），审计时间 2026-11-18 11:05 CST
- 方法：只读源码 + `gh run/api`；未构建 App（无 Xcode）。期间未改仓库任何受控文件（`cargo metadata` 刷新了已被 gitignore 的 `core-mobile/target/.rustc_info.json` 缓存）。

## 结论：**不可发**（按商店发布标准）

工程质量本身很高（CI 四个 job 全绿、零 TODO/print、隐私清单齐全、Mock 在 Release 不可达），但**"发 v1.0 = 上架 App Store / Google Play"**这个目标有硬阻塞：Android 原生库不满足 16 KB 页对齐、Release 包用 debug 签名、两端 Release 配置从未在 CI 编译过、mihomo 的 GPL-3.0 静态链接没有任何许可处理、真机三项（NE 50 MB、Release 链接、真实 VPN 流量）仍未验证。

如果 v1.0 只是**内部里程碑 tag `mobile-v1.0`（不分发二进制）**，可视为**有条件可发**：等 `6ffbaa2` 的 iOS job 跑完变绿即可打 tag，但要在 tag 说明里写明下面的 P0 未解决，不能作为商店构建。
